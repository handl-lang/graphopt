# Vocabulary — originality is a vocabulary event

**Method.** Every committed overnight discovery ledger, split by one protocol field: `mint: corpus-prim` (the machine may name a new operation) versus every other mint mode (it may only compose rules the bank already has). Both arms run over held-out zoo modules, through the same referee (oracle → pay → sweep → cert) and the same novelty sieve.

### NEGATIVE — Composing rules the bank already has never yields a machine-original law.

### WIN — The difference is the vocabulary, not the corpus: both arms run over the same held-out zoo modules and the same referee.

## What this establishes, and what it does not

- It establishes the **control**: over every fixed-bank run on real corpora, zero admitted laws were machine-original. The claim that composition cannot produce novelty is not an argument here, it is a measured floor.
- It does not establish that vocabulary growth *pays* — originality and payoff are separate axes (`docs/results_bank_growth.md`: +0.066 iff it pays).
- The runs are all on the same box, one seed per ledger, and the depth-3 arm already carries 2 known-art admissions — the fraction is not forced to 1 by construction.
